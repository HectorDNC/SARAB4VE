# Logos de aliados

Para agregar un aliado real a la sección "Aliados" del home:

1. Pon su logo acá (PNG o SVG, fondo transparente si es posible).
2. En `frontend/src/app/(webpage)/page.tsx`, en el array `ALIADOS`, agregá o
   editá una entrada con `logo: "/aliados/tu-archivo.png"`.

Mientras una entrada no tenga `logo`, la tarjeta muestra el nombre como
texto en su lugar.
