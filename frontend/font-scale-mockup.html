🔤 Control de Escala de Fuente

Propuesta de ubicación e implementación para mejorar accesibilidad en SARA

📖 Historia de Usuario

Como usuario con baja visión o dificultad para leer texto pequeño
Quiero poder incrementar el tamaño de la fuente en toda la aplicación hasta 200%
Para que pueda leer el contenido con mayor claridad y comodidad

✅ Criterios de Aceptación

  • Botón visible y accesible en la barra superior en todas las páginas
  • Control que permite 4 niveles de escala: 100%, 125%, 150%, 200%
  • La preferencia se persiste en localStorage
  • Se aplica instantáneamente a todo el contenido
  • Funciona en desktop y móvil
  • Totalmente accesible (aria-label, focus visible, teclado)
  • No hay saltos de layout al cambiar escala

🔧 Implementación Técnica (Opción C)

1. Crear componente FontScaleControl.tsx

"use client"; import { useEffect, useState } from "react"; export default function FontScaleControl() { const [scale, setScale] = useState(100); const scales = [100, 125, 150, 200]; useEffect(() => { // Cargar del localStorage const saved = localStorage.getItem("fontScale"); if (saved) { const value = parseInt(saved, 10); setScale(value); applyScale(value); } }, []); const applyScale = (value) => { document.documentElement.style.fontSize = `${(value / 100) * 16}px`; localStorage.setItem("fontScale", value.toString()); }; return ( <button onClick={() => applyScale(125)} > {scale}% </button> ); }

2. Integrar en Navbar.tsx

import FontScaleControl from "@/components/ui/FontScaleControl"; // En el JSX del header, después del logo: <FontScaleControl />

3. Actualizar globals.css

html { font-size: 16px; /* Base por defecto */ } body { font-size: 1rem; /* Hereda del html */ } /* Todos los elementos usan rem o em para escalar */
